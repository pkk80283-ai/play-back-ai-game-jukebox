# PLAY//BACK visual system

The three references are separated by role, then recombined through one shared UI grammar.

- Reference 1 → world layer: cobalt desktop sky, acid-green field, cropped globe, old utility windows, desktop icons and a giant cursor.
- Reference 2 → interaction layer: an incoming Y2K signal, clamshell-phone focal object, answer/decline selection, signal rings and halftone collage.
- Reference 3 → narrative layer: eccentric webmaster NPC, RPG dialogue hierarchy, oversized cropped pixel typography and CRT/moire texture.

Shared tokens: cobalt `#1438d4`, chartreuse `#dfff00`, cyan `#16f4ff`, CRT off-white `#f2f1e8`, Win98 gray `#c8c8c8`, black `#050505`. Geometry is square, borders are hard, shadows are offset and controls use a Win98/RPG hybrid treatment. Cyan/magenta chromatic separation is reserved for the PLAY//BACK wordmark.

Generated concepts in this folder are implementation references, not runtime UI screenshots. Runtime labels, buttons, forms and windows remain code-native.
